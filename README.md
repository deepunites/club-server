# club-server

Серверная часть гибридного бездиска для компьютерных клубов: Windows стоит локально на каждом ПК, по сети
раздаётся только библиотека игр — read-only iSCSI-том (клон ZFS) с TrueNAS SCALE 25.10+.

Сервер **не зависит от шелла**: касса, игроки, сессии, тарифы и деньги — зона шелла (ClubShell, Senet,
iCafeCloud и т. п.). Со стороны ПК с сервером работает только наш помощник бездиска (служба Windows).

.NET 10, PostgreSQL 18, TrueNAS SCALE 25.10+.

```
src/Club.Server      ASP.NET Core: API бездиска для помощника, API панели, оркестрация библиотеки
src/Club.TrueNas     JSON-RPC-клиент middleware TrueNAS (wss, API-ключ, закреплённая версия API) и операции с томами/iSCSI
docs/diskless-api.yaml  спецификация API бездиска (OpenAPI 3.1); .json генерирует scripts/build-spec.sh
docs/panel-api.md    API панели администратора
docs/research/       исследование API TrueNAS и стека .NET (источники и статусы проверки)
tests/               интеграционные тесты: временная база PostgreSQL, поддельный TrueNAS с TLS
```

## Что реализовано

- **API бездиска** (`/diskless/v1`, `docs/diskless-api.yaml`): регистрация машины по `X-Club-Key` и HWID (номер места
  выдаёт сервер, MAC для DHCP/PXE), JWT RS256 и одноразовый refresh, «какой том монтировать», отчёт помощника о
  фактическом состоянии тома (в ответе — актуальный том). Отчёт отмечает машину «на связи» — по нему считается подписка.
- **Библиотека игр** (`src/Club.Server/Library`, секции `Library` и `TrueNas`): версии хранятся как намерения в БД,
  операции publish/rollback — в журнале; единственный фоновый исполнитель (advisory lock). Публикация: снапшот
  мастер-zvol → RO-клон → extent (ro) → target с версией в имени → LUN → новая версия текущая, прежняя — откатная,
  ещё более старая разбирается (таргет без force: пока ПК подключены — ждём). Недоступный TrueNAS не тратит попытки,
  падение на любом шаге — операция выполняется заново. Сверка только пишет предупреждения (`storage_warnings`).
- **API панели** (`/panel/api/v1`, `docs/panel-api.md`): обзор библиотеки, публикация, откат, повтор упавшей операции,
  предупреждения. Доступ пока по одному токену `Panel:AdminToken`.
- Миграции FluentMigrator с откатом; тест прогоняет откат до пустой базы и обратно.

Не сделано: помощник бездиска (служба Windows), реестр машин в панели и одобрение новых машин, Kea DHCP/PXE,
образы Windows и перезаливка, остальные экраны и фронтенд панели, вход в панель по учётным записям.

## Запуск

```bash
createdb club_dev
ASPNETCORE_ENVIRONMENT=Development dotnet run --project src/Club.Server --urls http://127.0.0.1:5080
```

Тесты (нужен локальный PostgreSQL с правом CREATEDB у текущего пользователя):

```bash
dotnet test ClubServer.sln
```
